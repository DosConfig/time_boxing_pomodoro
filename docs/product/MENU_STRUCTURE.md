# Menu Structure

## Product Frame

Timebox Mark is an app-first timeboxing planner. The current product should minimize user touch and typing while helping users build a daily plan, start the active box, and sync the result to calendar later.

Notebook capture is a future expansion, not the current primary flow.

## Primary Navigation

```text
Today
Focus
Calendar
Settings
```

## Today

The daily planning surface.

- Date selector
- Fast Brain Dump
- Top 3 Priorities
- Time Box Grid
- Start selected box
- End-of-day Review entry point

## Focus

The execution surface.

- Current time box
- Countdown timer
- Pause / resume / reset
- Local alerts
- Live Activity

## Calendar

The provider connection and sync surface.

- Apple Calendar
- Google Calendar
- Outlook / Microsoft 365
- Sync status
- Event conflict review
- Provider diagnostics

## Settings

The app configuration surface.

- Default timeboxing granularity
- Pomodoro presets
- Local alerts
- Sound
- Live Activity privacy
- Calendar provider settings
- Sign in

## Secondary Screens

- Review
- Calendar Conflict Resolver
- Connected Provider Detail
- Privacy and Legal

## Future Expansion

### Notebook Capture

The notebook-to-calendar bridge should be added after the app-only timeboxing flow is useful.

- Camera capture
- Image crop / rotate
- OCR result review
- Top 3 extraction
- Time box extraction
- Conflict review before calendar sync

### Notebook Store

- Notebook SKU
- Product detail
- Order history
- Support

## Live Activity Hierarchy

```text
Top priorities
Current time box
Remaining time
Session / progress
```

Lock Screen can show Top 3 and the current time box. Dynamic Island should show only the current time box, the first priority when space allows, and the countdown.
