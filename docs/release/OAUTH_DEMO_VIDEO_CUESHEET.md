# OAuth 심사 데모 영상 촬영 큐시트 (calendar.events)

목표: 1~2분 원테이크. 심사관이 (1) 이 프로젝트의 OAuth 클라이언트, (2) 앱이 calendar.events 권한을 동의받는 과정, (3) 실제로 캘린더에 이벤트를 만드는 것을 순서대로 확인할 수 있어야 한다.

Google 요건: 영상에 이 프로젝트의 모든 OAuth 클라이언트가 나와야 하고, 실제 동의 화면과 스코프 사용이 보여야 한다.

---

## 준비 (촬영 전)

1. 로그인 계정: 본인 Google 계정 하나 준비 (테스트 사용자 아니어도 됨)
2. 앱 상태: Google 로그인과 캘린더 내보내기가 실제로 동작하는 빌드여야 함 (OAuth 클라이언트 ID, iOS URL scheme 설정 완료). 안 되면 동의 화면이 안 떠서 촬영 불가 → 이건 촬영 전에 실기기에서 한 번 눌러 확인
3. 언어: 가능하면 앱/기기를 영어로 두면 심사관이 편하지만, 한국어여도 통과됨 (선택)
4. 녹화 방식: 아래 "원테이크 촬영법" 사용

## 원테이크 촬영법 (맥 하나로 브라우저 + 폰 동시 녹화)

1. 아이폰을 케이블로 맥에 연결
2. QuickTime Player > 파일 > **새 동영상 녹화** > 녹화 버튼 옆 화살표에서 소스를 **아이폰**으로 선택 → 폰 화면이 맥 창에 미러링됨 (여기서 QuickTime 자체 녹화는 시작 안 해도 됨, 미러 창만 띄우면 됨)
3. 맥 화면 녹화 시작: `Cmd + Shift + 5` > "전체 화면 기록" > 기록. 이제 브라우저와 폰 미러 창이 한 화면에 다 잡힘
4. 아래 장면 순서대로 진행
5. 끝나면 `Cmd + Shift + 5` > 중지 → 바탕화면에 mp4 저장

(대안: 시뮬레이터면 `xcrun simctl io booted recordVideo ~/Desktop/oauth-demo.mp4`로 폰 부분만, 브라우저 부분은 따로. 원테이크가 더 깔끔하니 위 방법 권장)

---

## 장면 순서 (녹화하면서 이대로 클릭)

### 장면 1 (약 0:00~0:15) — OAuth 클라이언트 보여주기
- 브라우저에서 Google Cloud Console > Google 인증 플랫폼 > **클라이언트** 페이지 열기
- 이 프로젝트의 OAuth 클라이언트 ID 목록(iOS, Android 등)이 다 보이도록 천천히 스크롤 (요건: 모든 클라이언트 노출)
- 이어서 **브랜딩** 또는 **개요**에서 앱 이름 "Timebox Mark"가 보이게 잠깐

### 장면 2 (약 0:15~0:45) — 앱에서 권한 동의
- 폰 미러 창을 앞으로 → Timebox Mark 실행
- **Google로 로그인** 탭 → 계정 선택
- (프로덕션 미인증 상태라 "확인되지 않은 앱" 경고가 먼저 뜰 수 있음 → 고급 > 계속 눌러 진행. 이 화면 나와도 괜찮음)
- **동의 화면**이 뜸: "Timebox Mark이(가) ... 모든 캘린더의 일정 보기 및 수정" 문구가 보이는 순간 **2~3초 멈춰서** 확실히 보이게
- 허용 탭

### 장면 3 (약 0:45~1:05) — 스코프 실제 사용
- Today 화면에서 타임박스 하나 추가하거나 선택
- **Google 캘린더로 내보내기** 실행
- 내보내기 성공 표시(스낵바 등)가 보이게

### 장면 4 (약 1:05~1:25) — 결과 확인
- 브라우저에서 calendar.google.com 열기 (같은 계정)
- 방금 만든 이벤트가 캘린더에 생성된 것을 보여줌 (타임박스와 시간/제목이 일치)

### 자막/내레이션 (권장)
- 영상 어딘가에 한 줄: "Timebox Mark uses the calendar.events scope only to create events that the user chooses to export to their own Google Calendar."

## 업로드

1. YouTube studio.youtube.com > 만들기 > 동영상 업로드 > mp4 선택
2. 공개 상태를 **"일부 공개(Unlisted)"** 로 설정 (전체 공개 아님)
3. 게시 후 나오는 링크 복사
4. Google Cloud Console > 데이터 액세스 페이지의 **"데모 동영상 YouTube 링크"** 칸에 붙여넣기 → 저장

---

## 주의

- 컷 편집 없이 한 번에 이어 찍는 것을 권장 (심사관은 인증적인 흐름을 선호)
- 동의 화면의 권한 문구가 흐릿하거나 스쳐 지나가면 반려 사유가 됨 → 반드시 2~3초 멈춤
- 클라이언트 목록을 안 보여주면 반려 → 장면 1 빠뜨리지 말 것
- 영상에 개인 이메일/비번 입력 화면이 찍혀도 무방하나, 비번 타이핑은 굳이 클로즈업하지 말 것
